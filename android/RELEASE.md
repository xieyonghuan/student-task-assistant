# 拾课 Android v1.4.1 · 接收修复与任务图片卡片

- 修复微信、QQ“用拾课打开”截图不被接收的问题，支持内容 URI 和通用文件类型声明，并按图片实际字节校验；不接受 PDF 或任意本机路径。
- 首页“接收 / 粘贴通知”现在也能提取已复制的文字；读取失败时可手动粘贴，不再只提示到其他应用重新分享。不在后台读取剪贴板。
- 默认快速模式只执行一次原生识别，不再自动启动第二套识别引擎。需要难字核对时，可选择“精细复核（较慢）”。具体耗时仍取决于设备和图片。
- 自动提取课程名称，确认页支持修改；课程随任务保存、搜索、备份和分享。保留旧任务，数据库及 JSON 备份版本保持不变，仅增加可选课程字段。
- 改善跨行相对日期及英文 next Monday 等时间提取。新增“通知发出日期”和重算按钮：旧通知需按其实际发出日计算，截图没写消息日期时请手动核对。
- 分享任务可生成图片卡片，包含课程、任务名、截止时间及要求，先预览再选择微信、QQ或其他应用。每张最多十项，内容过长时可分批；文字分享及复制仍保留。
- 图片通过授权内容 URI 交给接收应用，不需相册或存储权限。图片缓存过期清理。
- 保留多图识别、重复作业提示、草稿恢复和保存后清理、日历自动同步与离线语音。

先在首页设置导出任务备份，再直接覆盖安装。包名、原签名与存储地址保持一致，不要先卸载或清除应用数据。

第三方应用需提供系统分享或“用其他应用打开”入口。网页端支持粘贴文字、分享文字及图片下载/浏览器分享，不注册 Android 系统接收目标。截图与识别内容不上传到识别服务器。

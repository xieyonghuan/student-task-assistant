# 拾课 Android v1.4.0 · 快捷分享与本机识别

- Android 优先使用随 APK 内置的原生中文识别模型，减少 WebView/WASM 识别等待；异常时切回原有备用离线引擎。图片在本机处理，无需下载模型。具体速度取决于设备和图片。
- 在微信、QQ、浏览器或相册使用系统分享 → 拾课，将文字、单张或多张截图直接送入提取确认页；第三方应用需提供系统分享入口。网页链接作为文字接收，不自动抓取网页。
- 分享先暂存在本机，合并已有导入草稿，保留手动填写。收件编号和草稿原子保存，成功写入后才清理队列，避免中断后丢失或重复导入。达到草稿限制时保留尚未处理的分享，可从首页“接收分享”继续。
- 任务卡片可分享单项；列表“分享任务”可勾选多项，预览名称、截止时间及要求，再选发送应用。支持复制内容，不自动发送给联系人。
- 修复附件大小误作编号、聊天文件和说明拆分、部分微信中英翻译与引用重复、空格分隔日期时间无法提取。原文仍可展开核对。
- 数据库仍为 v2，任务备份仍为 v1；草稿和截图不包含在备份中。网页端继续使用原有离线 OCR，支持向外分享或复制，不注册 Android 系统接收入口。
- Android 识别使用内置 ML Kit 中文模型（16.0.1），截图不上传到识别服务器。微信/QQ 在 ColorOS 上的具体分享菜单及设备实际速度仍需实机核对。

以下既有功能继续保留：

- 一次选择多张课程通知截图，逐张识别后汇总为可编辑清单，再统一确认保存。最多 20 张、每张不超过 20 MB、总计不超过 100 MB。
- 自动提示不同截图中疑似重复的作业，保留来源及原图供核对；可取消重复项。与已有任务重复时仍由用户选择跳过、新增或修改原任务。
- 单张失败不丢失其他识别结果，可重试失败截图或跳过。
- 识别进度、确认表单和手动填写自动暂存在本机；意外刷新或退出后，可恢复上次内容，只继续未完成的截图。
- 任务保存与对应草稿移除在同一次事务中完成；整批处理完成或主动放弃后自动清理暂存截图。
- 数据库 v1 原有任务保留并升级至 v2，新增草稿仓库；任务 JSON 备份格式保持 v1，不导出未保存草稿。升级前建议备份，请直接覆盖安装，不要先卸载。
- 保留 v1.2.4 的识别提速、平板侧栏及首页设置入口。
- 继续支持本地 OCR、离线语音、独立任务确认页面和自动日历同步。

已安装 v1.1 或 v1.2（含 v1.2.2）的设备可直接覆盖升级，包名、签名、存储地址与数据格式保持一致。升级前建议在首页设置中导出备份；不要先卸载。跨设备使用时，先导出 JSON 备份，再在新设备恢复。

安装 APK 后，在“设置与帮助 → 管理自动同步”开启日历权限。保存有截止日期的任务时，会自动写入本机的“拾课 · 学习任务”日历，无需导入文件。

- 修改任务更新同一条日程，完成任务保留记录并取消提醒，恢复后重新提醒。
- 删除任务或移除截止日期时，会移除对应日程；暂停同步会保留已有日程，重新开启时再核对。
- 本地日历不使用云账号，截图和语音识别资源已内置，支持离线使用。
- 从原网页“导出备份”，在安装版“恢复备份”，即可迁移已有任务。两者的数据不会自动合并。
- 在 ColorOS 日历的日历列表中确认已显示“拾课 · 学习任务”，并允许日历通知。不同系统可能限制多次提醒，请先试一项任务。

程序使用本地私有密钥签名。以后升级请覆盖安装；卸载或清除应用数据前，先导出任务备份。

Android 自动化验证覆盖实际 Calendar Provider 的新增、更新、防重复、完成恢复、删除、暂停及不修改其他日程；另测试本地 WebView 通信、中文截图识别与语音模型加载，以及手机键盘弹出、关闭、横屏与大字体布局。OPPO Pad 3 和一加 Ace 3 的实际日历展示、麦克风及通知效果仍需实机确认。

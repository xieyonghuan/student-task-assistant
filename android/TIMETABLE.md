# Android 课程表（v2.0.0）

本轮增加本地课程表，不连接教务系统。网页 Pages 自动发布已停止，现有网站保持原版本。

## 操作

1. 首页“我的课程表”或侧栏“课程表”进入，创建课表，先填写第一教学周星期一、学期周数、每节课时长，以及上午、下午、晚上的节数；时段可设 0 节，每天合计 1–20 节。再按每页四节设置上课/下课时间，可手写或使用 Android 原生拨轮。修改上课时间按课长填写下课时间，仍可手动调整每节下课时间。预填作息是示例，需要核对。
2. 可手动添加课程，或一次选择最多 10 张课程表 / 课程列表截图。周课表需保留星期和节次栏；列表支持合并单元格、多次安排与跨图续行。识别后进入逐门确认页面，同一课程的多个安排在页内切换，确认和上一步固定在底部；可单独打开原图核对。缺失星期、周次、节次的课程可保存为待补全课程，不发提醒。
3. 周次支持 `1-16`、`1-16(单)`、`2,4,8-12`。同名课程的多个上课时段分别保留；完全相同的导入安排合并。
4. 点击周课表的某次课可调至另一日期 / 节次 / 地点，或本次停课。变更记录可撤销。课程列表编辑的是学期重复规则；已有调课不兼容时，需先撤销对应变更。
5. “上课提醒”选择一份主课表，默认提前 10 分钟，可设 0–120 分钟。当前查看的课表与主课表独立。通知与准确提醒权限分别设置；声音、振动遵循 Android 通知渠道。系统强行停止、关机及厂商省电设置会影响提醒。
6. 课程表备份与首页作业备份分开。恢复课程表备份替换课表，默认关闭提醒，不修改已有任务。
7. 点击周课表中的课程，可直接修改课程或删除；顶部“管理课程”也可选择待补全和学期其他周的课程。编辑支持切换同门课程的多个安排，名称/教师可同步，时间/地点仅修改所选安排。删除前明确选择“仅这一条”或“整门课全部安排”，同时移除对应调课与提醒；同名但教师不同的课程单独保留。
8. 修改时段节数时，下午、晚上的课程与调课会保持原时段内的位置，更新整体节次编号。仍有课程使用被减少的节次，或连堂课跨越新增时段时，会拒绝保存并提示先修改安排。旧课表/备份未含新设置时按原作息推导分组，时间不会被自动重写。
9. Android“已完成”入口位于“全部待办”页面上方，显示已完成数量；侧栏保留其他分类。

## 持久化与调度

- 包名、签名与 WebView 本地来源不变；任务 IndexedDB 不迁移。
- 课表的权威数据使用 Android `AtomicFile` 独立文件 `course-tables-v1.json`，含 schema/revision、课表、作息、规则与单次变更。保存前完整验证，拒绝旧 revision；损坏数据不会静默重建覆盖。
- 截图草稿在独立 IndexedDB `shike-course-drafts`；v2 将不可变图片与可编辑元数据分开存放，避免每次更新进度或打字都重写全部图片。旧 v1 内嵌图片的草稿可直接恢复，在下次原子保存时迁移；删除草稿或成功保存后在同一事务内清理对应图片。未确认结果不创建提醒。
- 相同原始图片按 SHA-256 复用本次草稿已有结果；表格单元格及局部数字按完整规范化像素摘要复用，保留原识别与数字复核规则。复用缓存只在识别进程短时保留，最多各 256 项，闲置一分钟或页面退出释放，不上传图片。相似图片或不同像素不会当作同一结果。
- `CourseEngine` 唯一计算上课实例，供周视图和原生提醒使用。采用 `Asia/Shanghai`，周次数组支持单双周和不连续周，连堂按一次课提醒。
- `CourseAlarms` 使用 AlarmManager，最多提前调度接下来 64 次，触发后及半天维护时续排。重启、升级、时间改变、重新授权和打开应用时重建；调课取消原时间并安排新时间。
- 通知前重读当前规则并检查主课表、提前量、时间与持久化送达记录，防止过期、重复或已删除安排通知。准确权限未授予时降级为可能延迟的系统提醒，UI 明确显示。超过开课一分钟的提醒不集中补发。
- 本功能不复制 WakeUp 源码、品牌或在线服务，不自动登录学校，不收集账号密码，不上传截图。

## 验证边界

Node 与浏览器测试覆盖解析、跨行周次误读、截图坐标、多时段去重、草稿恢复和清理、复制课表、主课表独立选择、调课与移动布局。用户提供的七张原图仅在本机使用真实模型验证：汇总为 11 门课程、34 个安排，其中 33 个有完整上课信息；只有周次的课程保持待补全，不根据其他课程猜时间。原图与 OCR 中间内容位于被 Git 忽略的本机测试目录，不上传仓库或 CI。

Android 仪器测试验证原生原子保存、revision 冲突、周次、跨周调课、通知与 AlarmManager，以及原生时间拨轮的确认和取消。真实 ColorOS 熄屏、重启、省电策略仍需设备验收。

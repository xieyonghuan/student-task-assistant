供 OPPO Pad 3 和一加 Ace 3 使用的本地学习任务助手，提供 PWA 和 Android 安装版。浅色玻璃界面，支持横竖屏。当前为 **v1.2.3**。

## 已实现

- 上传一张课程通知截图，使用本机的简体中文和英文 OCR 识别；也可以直接粘贴通知文字。
- 尽量提取通知中的多项任务，逐项修改、确认和保存，不自动批量入库。
- 记录任务名称、截止日期和时间、具体要求。
- “明天”“后天”分别在设备本地日历上顺延一天、两天；未限定的“周五”取尚未到期的下一次周五，“本周五”“下周五”按指定周计算。缺失、模糊或冲突日期会弹出带任务名称的日期确认框；允许选择“暂无截止日期”。
- 按截止时间管理待办，分列逾期、无日期、已完成任务；支持编辑、搜索、删除、完成与恢复。
- 提示相同或相似任务，支持跳过、新增、修改原任务。
- 生成 `.ics` 日历文件，默认选中全部有截止日期的任务（含已完成任务），你可以取消勾选。
- 日期未填写时间时，按**所选日期当天 00:00，中国标准时间 UTC+8**截止，并非当天结束时。
- 默认提前 3 天、1 天、5 小时、1 小时各生成一个提醒，可在导出时取消勾选。
- 任务存入当前浏览器的 IndexedDB；支持 JSON 备份与恢复。
- 首次联网准备约 47 MB OCR 资源后，可以离线重新打开、识别和管理任务。
- 语音模型资源与 OCR 分开准备：不使用语音时不必下载语音模型。

## 用语音添加

1. 打开首页，点击“开始语音输入”。
2. 首次点击“准备语音资源”（约 47 MB）；等待“中文语音资源已就绪”。
3. 点击“开始说话”，允许浏览器使用麦克风，等待提示“正在听”。尽量用普通话清楚地说出任务。
4. 点击“停止并转写”，核对并修改文字。需要补充时可再次点击“开始说话”，新一段会追加在已有文字后。
5. 点击“整理为任务”，逐项确认任务信息。“明天”等明确相对日期按提取时设备的本地日期自动填写；界面会显示参考设备时间，你可以改动。保存后固定为具体日期，不会每天重新顺延。
6. 点击“确认并保存”，最后回到任务时间轴。

录音只在内存中流向本机识别线程，不存入备份或上传服务器。关闭语音窗口即释放麦克风。不支持麦克风或本地音频处理的浏览器会显示说明，可改用手动输入。需要 HTTPS 安全网址（电脑 localhost 除外）。

## 电脑上体验

在当前目录打开终端，首次执行：

```powershell
npm ci
npm run build
```

之后双击目录中的 **打开拾课.cmd**，或执行：

```powershell
node scripts/serve.mjs --open
```

浏览器地址为 `http://127.0.0.1:4173/`。保持终端窗口打开；不使用时关闭它即可。

不要直接双击 `dist/index.html`，`file://` 不支持所需的 Worker 与离线安装。

开发时使用 `npm run dev`。开发模式不注册离线 Service Worker；验证离线请使用构建后的版本。

## 在 OPPO Pad 3 上安装

1. 需要将 `dist/` 内的静态文件放到一个平板可访问的 **HTTPS 安全网址**（例如该公开仓库的 GitHub Pages）。这只托管程序与通用 OCR 模型，没有任务服务器。
2. 用平板浏览器打开该网址，通过菜单中的“安装应用”或“添加到桌面”安装。实际入口因浏览器版本而异。
3. 进入“设置与帮助”，点击“准备离线使用”，等到出现“离线资源已就绪”。
4. 断网，重新打开应用并用一张清晰截图测试。

**电脑的 localhost 只供电脑本机使用，平板无法用它打开应用。普通局域网 HTTP 地址也不能提供完整 PWA 离线安装。** 正式发布使用 GitHub Pages 的 HTTPS 网址。

可使用 `npm ci && npm run build` 构建，再将 `dist/` 内容作为网站根目录部署。项目使用相对资源路径，支持 `/student-task-assistant/` 子目录。

## 一次完整的使用流程

1. 点击“识别课程截图”，选一张 PNG、JPG、WebP 或 BMP（最多 20 MB）。可先裁剪到通知正文。
2. 等待本地识别；在导入页面核对、修正文字，再点击“从文字提取任务”进入确认页面。
3. 在独立确认页面逐项核对任务名称、日期和具体要求，可展开原文与截图对照。有遗漏可回首页手动添加。
4. 碰到日期确认框，先看它对应的任务名称，再选日期或“暂无截止日期”。
5. 点击“确认并保存”，完成后回到任务列表。
6. 点击任务圆圈标记完成，在“已完成”列表中可恢复。
7. 点击“导出日历”，确认选中的任务和提醒，下载 `.ics`。在平板上打开文件，选择日历应用导入。
8. 定期在“设置与帮助”中导出任务备份；日历文件不等于完整备份。

## 数据与限制

- 截图、识别文字和任务不上传服务器，不使用云端 AI、第三方统计、在线字体。浏览器会从当前网址获取应用代码和公开 OCR 模型。
- 原截图仅保留在本次核对页面中，不随任务保存；关闭导入窗口后释放。
- 清除站点数据、换浏览器、换网址、使用无痕模式，可能导致本地任务不可用。离线缓存也可能在空间不足时被浏览器回收；请定期导出备份。
- OCR 与本地规则提取会受截图清晰度和排版影响，可能漏掉或误识别任务，**请逐项核对**。明确的相对日期也按当前设备日期解析；如果是以前发出的通知，请核对并修改。周末、多个冲突日期等仍需确认。
- 已验证 `.ics` 结构、北京时间转换、中文转义、行折叠和四个提醒。**尚未在真实 OPPO Pad 3 / ColorOS 日历上验证安装、导入和提醒**。日历可能忽略部分提醒；过去的提醒时间也不会补发。
- 修改、完成或删除本地任务，不会同步修改已导入的日历事项。重复导入可能重复创建事项，需在日历中检查。
- 第一版不包含账号、多设备同步、批量截图自动处理。后续自动化会在逐项确认流程稳定后加入。

## 验证

```powershell
npm test
npm run build
```

浏览器测试需要已安装的 Microsoft Edge。在一个终端执行 `npm run preview`，另一个终端执行：

```powershell
npm run test:browser
```

测试使用独立的临时浏览器，不读写日常浏览器里的任务。覆盖任务增删改、持久化、重复处理、逐项确认、备份、日历、横竖屏与窄屏、断网重开与**真实中文 OCR**。通知图片由测试在本地生成，不含真实个人信息。

语音测试使用浏览器生成的测试麦克风，不读取真实麦克风：验证本地中文模型离线加载、音频送入、最后一句收尾、转写修改与保存、权限拒绝、取消后麦克风释放。真实说话内容的准确度和 OPPO Pad 3 的麦克风兼容性仍需实机验证。

另外提供可选的原图回归测试：在终端设置 `STUDY_TEST_IMAGE` 为本地测试截图的完整路径后运行浏览器测试。测试图不会复制到仓库，也不会随程序发布；常规运行会跳过这项私人样本测试。

## 开发说明与来源

- Vite 构建、原生 JavaScript、IndexedDB、自定义 Service Worker。
- [Tesseract.js 官方文档](https://github.com/naptha/tesseract.js/blob/master/docs/api.md)和[本地资源配置](https://github.com/naptha/tesseract.js/blob/master/docs/local-installation.md)。运行时与中英文模型全部从锁定的 npm 依赖复制到本项目，不使用运行时 CDN。
- 中文和英文模型来自 [naptha/tessdata](https://github.com/naptha/tessdata)。
- 本地语音使用 [Vosk-Browser](https://github.com/ccoreilly/vosk-browser) 和 [Vosk 官方小型中文模型](https://alphacephei.com/vosk/models)。首次构建从官方源分段下载并核验固定 SHA-256，然后转换为浏览器模型包；运行时只从当前站点读取资源。
- 语音工作线程单独加载并在内存中解包，模型归档由 CacheStorage 管理；保留页面原有 CSP，不启用页面级动态代码执行。第三方修改及许可证见 `public/licenses/NOTICE.txt`。
- [RFC 5545：iCalendar](https://www.rfc-editor.org/rfc/rfc5545)。
- 生成的 `public/ocr/`、`dist/`、用户数据与日历文件不纳入 Git；`package-lock.json` 纳入 Git 以便复现构建。
